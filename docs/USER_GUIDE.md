# Инструкция пользователя «Быстрый список»

## Установка

1. На планшете/телефоне откройте https://russkin.github.io/purchases/
2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
3. Закрепите планшет на кухне, держите приложение открытым — после разблокировки список виден сразу (до 2 сек).

## Режим «Добавление» (дома, альбомно)

1. В меню (☰) выберите «Добавление».
2. Нажмите «+» → введите название категории (например, «Молочка»).
3. Нажмите категорию → откроются товары. Нажмите «+» → введите названия (Молоко, Кефир…).
4. Нажимайте большую кнопку товара — счётчик в углу растёт (+1 за нажатие).
5. Маленькая кнопка «−» уменьшает количество.
6. Долгое нажатие 3 сек на кнопку — переименовать; сотрите текст полностью — вернётся «+».

## Режим «Список» (магазин, вертикально)

1. В меню (☰) выберите «Список».
2. Положили товар в корзину — поставьте галочку: товар зачеркнётся и уйдёт в конец категории.
3. Отметили всё в категории — категория уйдёт вниз списка.
4. Передумали — снимите галочку, товар вернётся.
5. Долгое нажатие 3 сек на строку — удалить товар из списка насовсем (название кнопки сохранится).
6. Отмеченные товары сами удаляются из списков в конце суток.

## Кнопки в меню

- «Очистить список» (с подтверждением) — обнуляет количества и галочки.
- «Очистить все кнопки» (с подтверждением) — стирает все названия категорий и товаров.

## Синхронизация между устройствами (необязательно)

Без неё каждое устройство живёт своим списком (для одного планшета достаточно).
Чтобы списки были общими: в меню введите `owner/repo` и GitHub token (хранится только на этом устройстве), «Сохранить», затем ⇅. Кто позже изменил — та версия побеждает.

## Если что-то не так

- Список не открылся в магазине — включите режим «Список» заранее дома: страница и данные уже в кэше, интернет не нужен.
- После обновления сайта первый запуск может занять чуть дольше — дальше снова быстро.
