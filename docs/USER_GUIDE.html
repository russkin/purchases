Инструкция пользователя «Быстрый список»

Установка

  1. Откройте Быстрый список.
  2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение» (или ⚙ → «📲 Установить приложение»).
  3. Держите приложение открытым на кухонном планшете — после разблокировки список виден сразу (до 2 сек).

Кнопки вверху экрана

  • Д / С — переключение режимов: Д — добавление (дома), С — список (магазин). Рядом — версия приложения.
  • ⇅ + скорость — интернет: зелёные — есть, серые — нет. Под стрелками — замеренная скорость. На iPhone скорости нет.
  • Посылочка — состояние синхронизации: зелёная — всё отправлено, жёлтая мигает — идёт отправка, красная — ошибка, серая — синк выключен. Красный «!» — ошибка 409: нажмите на него, отправка повторится.
  • ⚙ — меню (ниже — все пункты по порядку).

Режим «Добавление» (дома)

  1. Категория → товары; «+» — новое название.
  2. Внизу товара: «−» слева уменьшает, «+» справа добавляет. Клик по плитке количество не меняет.
  3. Количество — вверху над названием; ноль не пишется.
  4. Синяя обводка — есть что-то в корзине; красная — отмечен купленным, «−»/«+» заблокированы.
  5. Долгое нажатие 3 сек — переименование (товары внутри сохраняются). Кнопки: Сохранить / Очистить / Отмена. Тёзка в другой категории — предупредим и спросим.
  6. Вход в категорию мотает товары наверх; «← Категории» возвращает на то же место.

Режим «Список» (магазин)

  • Количество слева, дальше галочка и название.
  • Галочка — товар зачёркнут и уходит в конец категории; вся отмеченная категория уходит вниз.
  • Снятие галочки возвращает товар.
  • Долгое нажатие 3 сек на строку удаляет товар из списка (с подтверждением, название сохраняется).
  • Отмеченные товары исчезают сами после полуночи по часам устройства.

Меню шестерёнки ⚙ (по порядку)

  • «📤 Поделиться списком» — корзина текстом (категория со звёздочкой и двоеточием, товары с количеством). На телефоне — системное меню, иначе текст скопируется.
  • «🗂 Категории и товары» — подменю: «↕ Порядок» (стрелки двигают, ⏮ ⏭ — в начало/в конец; выход — повторный тап, тап по названию вверху или Д/С), «💾 Запомнить названия» / «↩ Восстановить названия» (страховка, заполняет только пустое), «Очистить список», «Сбросить все названия» (на всех устройствах!).
  • «🔗 Поделиться приложением» — ссылка на приложение через системное меню.
  • «📲 Установить приложение» — системный диалог (в установленном прячется сам).
  • «⇅ Синхронизировать» — вручную (обычно всё само).
  • «Очистить кэш» — лечит старое отображение (с подтверждением).
  • «🔑 Репозиторий и токен» (только для администратора) — окно: owner/repo, GitHub token, «Годен до» (только цифры, точки сами), «Отмена»/«Сохранить».
  • «ⓘ Информация для диагностики» — версия, репозиторий, синк, срок ключа, ошибки (кнопка «Поделиться» — прислать текст).
  • «📖 Инструкция пользователя» — эта страница.
  • «📋 Информация о версиях» — история всех версий.
  • «🔍 Поиск» — найти товар: введите буквы, тапните результат — откроется его категория с подсветкой. Кнопки ‹ › листают совпадения.

Синхронизация (необязательно)

  • Ссылка список не переносит! На каждом устройстве: ⚙ → «Репозиторий и токен» → repo + token + «Годен до» → «Сохранить» → «⇅ Синхронизировать».
  • Дальше само: через 2 сек после изменений, раз в минуту пока открыто, при открытии и возврате на вкладку; ошибки повторяются сами 5 раз. После возврата сети увидите «Связь восстановлена».
  • Кто позже изменил — тот и прав. Пустое устройство общий список не стирает.
  • Ошибка 409 лечится сама повтором или тапом по «!». Ошибка 401 — истёк или отозван токен, проверьте срок.
  • Все устройства — на свежей версии, часы — верные. Долго жёлтая посылка + крошечная скорость = слабая сеть, подождите.
  • У ключа есть срок: за 7 дней строка «Токен до …», за 3 дня и после — окно раз в сутки. Просрочили — синк встанет, списки останутся: впишите новый ключ и срок.

Обновления

  • Приходят сами: вопрос «Вышла новая версия — обновить?» при открытии и возврате на вкладку. Версия видна вверху экрана.

Если что-то не так

  • В магазине заранее включите режим «Список» — интернет не нужен.
  • Старое отображение после обновления — ⚙ → «Очистить кэш», сверьте версию вверху.
  • На новом устройстве пусто — «⇅ Синхронизировать», проверьте статус внизу и диагностику.
