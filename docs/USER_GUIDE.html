Инструкция пользователя «Быстрый список»

Установка

  1. Откройте Быстрый список.
  2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
  3. Держите приложение открытым на кухонном планшете — после разблокировки список виден сразу (до 2 сек).

Режим «Добавление» (дома)

  1. Меню ☰ → «Добавление».
  2. «+» → название категории (например, «Молочка»).
  3. Категория → товары: «+» → названия (Молоко, Кефир…).
  4. Большая кнопка — +1 к счётчику; маленькая «−» — −1.
  5. Долгое нажатие 3 сек — переименовать; пустой текст возвращает «+».

Режим «Список» (магазин)

  1. Меню ☰ → «Список».
  2. Галочка — товар зачёркнут и уходит в конец категории; вся отмеченная категория уходит вниз.
  3. Снятие галочки возвращает товар.
  4. Долгое нажатие 3 сек на строку удаляет товар из списка (название кнопки сохраняется).
  5. Отмеченные товары удаляются сами в конце суток.

Меню

  • «Очистить список» — сброс количеств и галочек (с подтверждением).
  • «Очистить все кнопки» — стирает все названия (с подтверждением).
  • Синхронизация (repo + token) необязательна; без неё всё работает локально и офлайн.
