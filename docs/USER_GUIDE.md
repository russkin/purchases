# Инструкция пользователя «Быстрый список»

## Установка

1. На планшете/телефоне откройте https://russkin.github.io/purchases/
2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение» (или ⚙ → «📲 Установить приложение»).
3. Закрепите планшет на кухне, держите приложение открытым — после разблокировки список виден сразу (до 2 сек).

## Кнопки вверху экрана

Слева направо:

- **Д / С** — переключение режимов. **Д** — добавление (дома), **С** — список (магазин). Нажатие меняет режим. Рядом показана версия приложения (например, v78).
- **⇅ + скорость** — интернет. Стрелки зелёные — сеть есть, серые — нет. Под стрелками — замеренная скорость (например, «1,25 МБ/с»). На iPhone скорости нет — так умеет только Android.
- **Посылочка** — состояние синхронизации: зелёная — всё отправлено, жёлтая мигает — идёт отправка (на слабой сети может мигать долго — просто ждите), красная — ошибка, серая — синк выключен (не введён ключ). Красный **«!»** вместо посылочки — не сошлось с другим устройством (ошибка 409): нажмите на него, отправка повторится.
- **⚙ (шестерёнка)** — меню (ниже — все пункты по порядку).

## Режим «Добавление» (дома)

1. Нажмите категорию → откроются товары. Кнопка «+» — новое название (категории или товара).
2. У каждого товара внизу две кнопки: **«−» слева** уменьшает, **«+» справа** добавляет. Нажатие на саму плитку количество НЕ меняет.
3. Количество показано **вверху над названием**. Ноль не пишется — пусто значит «не в корзине».
4. Категория или товар **обведены синим** — там есть что-то в корзине.
5. Товар **обведён красным** — он отмечен купленным (галочка в режиме списка): кнопки «−»/«+» на нём заблокированы. Снимите галочку — станет синим.
6. **Долгое нажатие 3 сек** на категорию или товар — переименование. Товары внутри категории при этом сохраняются. В окне три кнопки: **Сохранить**, **Очистить** (стереть название, кнопка снова станет «+»), **Отмена**. Если такое название уже есть в другой категории — предупредим и спросим.
7. Вход в категорию всегда мотает товары наверх; кнопка «← Категории» возвращает список категорий на то же место.

## Режим «Список» (магазин)

1. Количество — **слева**, дальше галочка и название.
2. Положили товар в корзину — поставьте галочку: товар зачеркнётся и уйдёт в конец категории. Отметили всё в категории — категория уйдёт вниз списка.
3. Передумали — снимите галочку, товар вернётся.
4. Долгое нажатие 3 сек на строку — удалить товар из списка (спросим подтверждение, название кнопки сохранится).
5. Отмеченные товары сами исчезают из списка **после полуночи** (по часам устройства). Названия при этом не стираются.

## Меню шестерёнки ⚙ (по порядку)

- **📤 Поделиться списком** — отправить корзину текстом: звёздочка и двоеточие после категории, товары с количеством через тире. На телефоне откроется системное меню, иначе текст скопируется.
- **🗂 Категории и товары** — подменю (раскрывается по тапу):
  - **↕ Порядок** — режим сортировки: стрелки двигают категории и товары, ⏮ ⏭ — в начало/в конец. Выход — повторный тап, тап по названию приложения вверху или переключение Д/С.
  - **💾 Запомнить названия / ↩ Восстановить названия** — страховка от случайных очисток: запоминает все имена на этом устройстве, восстановление заполняет только пустые кнопки.
  - **Очистить список** (с подтверждением) — обнуляет количества и галочки, названия оставляет.
  - **Сбросить все названия** (с подтверждением!) — стирает ВСЕ названия категорий и товаров на всех устройствах.
- **🔗 Поделиться приложением** — отправить ссылку на приложение через системное меню.
- **📲 Установить приложение** — системный диалог установки (в уже установленном приложении пункт прячется сам).
- **⇅ Синхронизировать** — отправить и забрать общий список вручную (обычно не нужно — всё само).
- **Очистить кэш** (с подтверждением) — чистит память приложения, списки и названия сохраняются, страница перезагружается. Помогает, если после обновления что-то выглядит по-старому.
- **🔑 Репозиторий и токен** (только для администратора) — окно с полями `owner/repo`, GitHub token (хранится только на этом устройстве) и «Годен до» (срок токена: только цифры, точки сами), кнопки «Отмена»/«Сохранить».
- **ⓘ Информация для диагностики** — версия, репозиторий, режим, состояние синка, срок ключа, ошибки, журнал. Рядом кнопка «Поделиться» — прислать текст, если что-то не работает.
- **📖 Инструкция пользователя** — эта страница.
- **📋 Информация о версиях** — история всех версий с изменениями.

## Синхронизация между устройствами (необязательно)

Без неё каждое устройство живёт своим списком (для одного планшета достаточно). Ссылка сама по себе список не переносит!

Чтобы списки были общими, **на каждом устройстве**: ⚙ → «Репозиторий и токен» → введите `owner/repo`, GitHub token и срок «Годен до» → «Сохранить» → «⇅ Синхронизировать».

Дальше всё само: отправка идёт через 2 секунды после каждого изменения, раз в минуту пока открыто, при открытии приложения и при возврате на вкладку. Пропала сеть — правки копятся; появилась и всё ушло — увидите «Связь восстановлена» (телефон ещё и прожужжит). Если отправка не удалась — приложение повторит само ещё 5 раз через 2 секунды.

Простые правила:

- Кто позже изменил — тот и прав. Не правьте один товар с двух устройств в одну минуту.
- Пустое устройство общий список не стирает — оно, наоборот, всё заберёт себе.
- Ошибка 409 («разминулись в дверях» — оба сохранились одновременно) лечится сама повтором или тапом по красному «!».
- Ошибка 401 — скорее всего, истёк или отозван токен: проверьте срок в настройках.
- Держите все устройства на свежей версии (номер вверху экрана) и проверьте часы — сильно сбитые часы ломают правило «кто позже».
- Посылка долго жёлтая, а скорость под стрелками крошечная — дело в слабой сети, просто подождите.
- У ключа синхронизации есть срок («Годен до» в настройках): за 7 дней внизу появится строка «Токен до …», за 3 дня и после срока — окно-напоминание раз в сутки. Просрочили — синк встанет (ошибка с намёком «токен истёк»), а списки останутся на устройствах: впишите новый ключ и срок в настройках.

## Обновления приложения

Приходят сами: приложение проверяет новую версию при открытии и возврате на вкладку и спрашивает «Вышла новая версия — обновить?». Соглашайтесь — страница перезагрузится уже новой. Номер версии виден вверху экрана и в диагностике.

## Если что-то не так

- Список не открылся в магазине — включите режим «Список» заранее дома: страница и данные уже в кэше, интернет не нужен.
- После обновления что-то выглядит по-старому — ⚙ → «Очистить кэш», сверьте версию вверху экрана.
- На новом устройстве пусто после ввода ключа — нажмите «⇅ Синхронизировать» и проверьте строку статуса внизу; в диагностике вместо прочерка не должно быть «выключен (нет ключа)».
